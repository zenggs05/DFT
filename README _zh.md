# 第一性原理计算方法与工具库 (DFT Utilities)

[![License](https://img.shields.io/badge/License-MIT-green)](LICENSE)

## 简介
欢迎来到 **DFT Calculation Methods & Utilities** 仓库。本项目旨在分享第一性原理计算（DFT）的相关方法、脚本文件以及实战教程，包括自动化构建复杂晶体模型、自动化输出输入文件等功能。

## 🖥️ 支持的软件
- **VASP**
- **CP2K**
- **Quantum ESPRESSO (QE)**
- **ABACUS** (国产原子算筹软件)
- **OpenMX**

## ✨ 核心功能
### 1. 复杂晶体模型自动化构建
自动化构建异质结、超胞、表面与界面模型及缺陷结构。
### 2. 输入文件自动化输出
一键生成 VASP/CP2K 标准输入文件，自动匹配赝势与 K 点设置。
### 3. 数据后处理
能带（Band）与态密度（DOS）的快速绘图与数据提取。
