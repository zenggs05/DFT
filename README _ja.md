# 第一原理計算手法とユーティリティ (DFT Utilities)

[![License](https://img.shields.io/badge/License-MIT-green)](LICENSE)

## はじめに
**DFT Calculation Methods & Utilities** リポジトリへようこそ。このプロジェクトは、第一原理計算（DFT）の手法、スクリプト、およびチュートリアルの共有を目的としています。DFTを使用する研究者や学生のための包括的なツールキットです。

## 🖥️ 対応ソフトウェア
- **VASP**
- **CP2K**
- **Quantum ESPRESSO (QE)**
- **ABACUS**
- **OpenMX**

## ✨ 主な機能
### 1. 複雑な結晶構造の自動構築
ヘテロ接合、スーパーセル、表面・界面モデル、欠陥構造の自動生成。
### 2. 入力ファイルの自動生成
VASP (`INCAR`) や CP2K (`cp2k.inp`) の標準入力ファイルの自動生成、および擬ポテンシャルの自動マッチング。
### 3. ポストプロセス（後処理）
バンド構造や状態密度（DOS）のプロット、データ抽出ツール。
