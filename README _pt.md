# Métodos de Cálculo DFT & Utilitários

[![License](https://img.shields.io/badge/License-MIT-green)](LICENSE)

## Introdução
Bem-vindo ao repositório **DFT Calculation Methods & Utilities**. Este projeto foca no compartilhamento de métodos de cálculo de primeiros princípios, scripts e tutoriais. Serve como um kit de ferramentas abrangente para pesquisadores e estudantes que trabalham com Teoria do Funcional da Densidade (DFT).

## 🖥️ Software Suportado
- **VASP** (Vienna Ab initio Simulation Package)
- **CP2K**
- **Quantum ESPRESSO (QE)**
- **ABACUS**
- **OpenMX**

## ✨ Funcionalidades Principais
### 1. Modelagem Automatizada
Construção de estruturas cristalinas complexas, superfícies, interfaces e defeitos.
### 2. Geração de Input
Geração automatizada de arquivos de entrada (`INCAR`, `cp2k.inp`) e correspondência de pseudopotenciais.
### 3. Pós-Processamento
Ferramentas para plotagem de estrutura de bandas/DOS e extração de dados.
